This is a game I made when I was 14 (in 2019) using Solar2D, atom, Inkscape, Krita.

It is a 2D puzzle game where the player reflects lasers onto blocks that must be destroyed. The player must be careful not to accidentally hit *explosive* TNT or ruin their chances of hitting the target blocks by destroying the anti-gravity bricks beneath them. There are three different worlds the player navigates, starting in the city and making their way to the industrial sites.

I used the Composer library from Solar2D to handle different game states.

This game can be run by downloading the zip in the folder "built game" and unzipping and then running the .exe. It can only run on Windows. 
The game can also be found and played at https://whisked.itch.io/laserase
